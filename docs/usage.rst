Usage
=====

.. _installation:

Installation
------------

To use Tadada, first install it using pip:

.. code-block:: console

   (.venv) $ pip install tadada

Creating recipes
----------------

To retrieve a list of random ingredients,
you can use the ``tadada.get_random_things()`` function:


For example:

>>> import lumache
>>> tadada.get_random_ingredients()
['shells', 'gorgonzola', 'parsley']
